# Rapido Clone — Frontend Web Application

A clean, responsive frontend clone of the **Rapido** bike-taxi and ride-booking landing page. Built to replicate the visual hierarchy, layout, and user-friendly interface of the Rapido web platform.

---

## Live Demo & Repository

- **Repository:** [github.com/Tharun855/Rapido-clone-](https://github.com/Tharun855/Rapido-clone-)
- **Main Entry File:** `index.htm`

---

## Features

- **Modern Navigation Bar:** Clean top header with navigation links and app download/call-to-action buttons.
- **Hero & Ride Booking Section:** Prominent pickup and drop location input fields styled after Rapido's booking interface.
- **Service Highlights:** Dedicated sections showcasing Bike Taxi, Auto, and Cab ride options.
- **Safety & Features Showcase:** Highlights rider safety standards, affordable fares, and quick doorstep pickup.
- **Responsive Design:** Adapts smoothly across desktop, tablet, and mobile screen sizes.

---

## Tech Stack

- **HTML5** — Semantic page structure (`index.htm`)
- **CSS3 / Bootstrap** — Responsive grid layout, utility styling, and clean UI components
